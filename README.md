## 🚀 Tecnologías y Arquitectura (2026)

Este proyecto ha sido optimizado con los estándares más exigentes del ecosistema web moderno:

- **React 19**: Arquitectura declarativa con renderizado reactivo de última generación.
- **TypeScript 5.8**: Tipado estático estricto para máxima robustez y prevención de errores.
- **Tailwind CSS v4**: Motor de estilos de alto rendimiento basado en variables nativas CSS y compilación instantánea.
- **Motion 12 (`motion/react`)**: Motor de físicas fluidas, orquestación de transiciones, arrastre táctil y efectos de parallax estilo Framer.
- **Lucide React**: Biblioteca de iconografía vectorial limpia y consistente.
- **Vite 6**: Empaquetador y entorno de desarrollo con Hot Module Replacement y división de chunks de proveedor (`manualChunks`).

## ✨ Características Principales

1. **Hero Inmersivo**: Visualización en profundidad de la silueta insignia (*KOVR APEX-70*), con botón de adquisición directa y contrastes cinematográficos.
2. **Header Adaptativo & Menú Framer**: Barra de navegación superior ultra limpia en móviles, integrando una bandeja de accesos rápidos (*Buscar*, *Deseos*, *Carrito*) con contador dinámico sin sobrecargar la pantalla.
3. **Carrusel de Tendencias Táctil**: Sistema interactivo con gestos de arrastre (*drag*), cálculo dinámico de anchos y filtros por categoría (*Hombre, Mujer, Kids*).
4. **Modal de Producto de Alta Gama**: Selector de tallas reactivo (EU 40–45), guía de equivalencias, especificaciones balísticas y botón de favoritos con feedback inmediato.
5. **Catálogo Completo con Filtros y Búsqueda**: Sistema de filtrado en tiempo real, búsqueda inteligente multicriterio y navegación paginada con desplazamiento suave.
6. **Drawer de Favoritos & Carrito**: Gestión sincronizada de artículos en memoria volátil de React.
7. **Checkout Seguro Simulado (SSL 256-bit)**: Pasarela de compra con confirmación instantánea, generación de código de orden y validación de entrega.
8. **Centro Legal & Soporte Unificado**: Módulos interactivos para Política de Privacidad (RGPD 2026), Términos de Servicio, Política de Cookies, Envíos/Devoluciones y Concierge 24/7.
9. **SEO y Datos Estructurados 2026**: Integración completa de etiquetas OpenGraph, Twitter Cards, meta *theme-color*, canonical links y Schema.org JSON-LD para motores de búsqueda.
10. **Seguridad y Anti-Hackeo**: Headers de protección HTTP (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`) y enlaces protegidos contra *reverse tabnabbing* (`rel="noopener noreferrer"`).

## 🛠️ Instalación y Puesta en Marcha

### Requisitos Previos
- Node.js 18+ (recomendado 20+)
- npm o pnpm o bun

### Pasos
```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/kovr-premium-sneakers.git

# 2. Entrar a la carpeta
cd kovr-premium-sneakers

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo en puerto 3000
npm run dev

# 5. Compilar para producción
npm run build

# 6. Probar build localmente
npm run preview
```

## 🌐 Despliegue en GitHub y Vercel

El proyecto incluye el archivo `vercel.json` preconfigurado con las reglas de redirección SPA y las cabeceras de seguridad requeridas:

1. **GitHub**: Sube el código a tu repositorio (`git push origin main`).
2. **Vercel**: Importa el repositorio desde el panel de Vercel. Selecciona el preset **Vite** y pulsa **Deploy**. No se requieren variables de entorno complejas para el despliegue del catálogo.
